# 架构复审

## 边界

- `ppt_slice` 负责从 URL 流式解码 P 视频、输出稳定 PPT 图片和疑似动态区间。
- 远程 MP4 不落盘；共享结果目录只保存最终 PPT 图片及 manifest。
- Harness 负责语料发现、冻结清单、运行证据、复核和统计，不改变生产 HTTP 契约。
- `dynamic_segments` 是 manifest 和终态回调的可选扩展；平台持久化不在本变更范围。

## 当前决策

- 动态检测与 PPT 页面去重使用独立阈值。
- 使用视频时间戳和四态状态机，候选切片延迟发布。
- 动态检测开启时解码参考帧并按 `sample_interval_ms` 限频；关闭时保留旧关键帧路径。该选择用于覆盖关键帧稀疏处约 7 秒的持续滚动，同时限制进入队列和比较器的帧数。
- 先采用像素变化与网格活动比例；只有校准证据证明不足时才增加方向一致性或光流。
- 课程级稳定哈希划分 70% 校准集和 30% 保留集。
- AI 只做初审，无法确定必须标记 `UNCERTAIN`。
- 全量真实扫描在隔离子进程执行；每视频具有可配置硬超时，超时进程终止后才有限重试，避免网络阻塞使整轮永久挂起。

## 完成门槛

完成声明必须绑定冻结语料。目录发现、视频处理、候选复核和漏报检查没有达到 100% 覆盖，或仍有不可访问、失败和 `UNCERTAIN` 条目时，不得标记全量验收通过。
