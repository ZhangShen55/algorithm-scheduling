# 里程碑 2A 通用调度运行时 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用真实 PostgreSQL、Redis、Kafka、`control-service`、`orchestrator-service` 和独立 HTTP 契约 Stub，贯通 `POST -> Outbox -> Kafka -> DAG -> 容量租约 -> Stub -> GET`，且任务状态只由运行中的 Worker 推进。

**Architecture:** `control-service` 继续只写 PostgreSQL 与 Outbox。`orchestrator-service` 的 FastAPI lifespan 持有 SQLAlchemy Engine、共享 HTTP Client、aiokafka Producer/Consumer、停止事件和必需后台循环；Consumer 成功初始化 DAG 后提交 offset，执行器先通过 control-service 取得容量租约，再领取节点、调用统一 Stub `/execute`、写入结果并汇总任务状态。2A 不处理真实媒体、不接真实 PPT/OCR/ASR/VBas，也不改变 A 面和现有算子契约。

**Tech Stack:** Python 3.11、FastAPI、SQLAlchemy 2、psycopg 3、httpx、aiokafka 0.12+、PostgreSQL 17、Redis 7.4、Kafka 4、pytest/pytest-asyncio、Docker Compose。
