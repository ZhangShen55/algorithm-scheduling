> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为里程碑 2B 建立从权威部署清单、真实注册/GPU/Smoke 证据和明确未执行声明到 write-once JSON/Markdown 报告的完整、可审计、fail-closed 发布链路。

**Architecture:** 新增一个版本化 report plan 和一个只负责证据合同/类型归一化的共享 Python 模块；聚合器从 Compose、Smoke manifest 与 release 目录精确推导期望集合，生成版本化 `summary/cases.json`，renderer 再按真实 evidence 类型验证、计算总状态并安全发布双报告。GPU v1 证据保持原格式，由适配器通过 `mode + 规范目录` 识别；negative/load 在没有现场 runner 时只能生成 write-once 的 `未执行及原因` 声明。

## 1. 范围与完成门禁

本计划只修改 `algorithm-scheduling-platform/` 下的 Harness/reporting 代码、测试和文档，以及本计划明确列出的历史实施计划。不得修改任何算子项目的应用代码、配置、Dockerfile、HTTP/WebSocket 合同或模型文件。

完成后必须满足以下不变量：

```text
权威 Compose + Smoke manifest + report plan
                         |
                         v
精确 registration/GPU/recovery/Smoke 集合 + 243 条反例/负载声明
                         |
                         v
              summary/cases.json (write-once)
                         |
                         v
     类型专属校验 + evidence 摘要 + overall_status
                         |
                         v
       summary/report.json + report.md (事务安全)
```

- 缺少预期文件、出现未知实例、错误 release/SHA、悬空 run ID、未知 evidence 类型或不安全路径时，不得发布 `summary/cases.json`。
- 合法的失败证据必须进入报告并形成 `失败`，不能因为聚合命令非零而丢失失败事实。
- 无现场 runner 的反例和负载项只能标记 `未执行及原因`，不得由本地单元测试、健康检查或正向 stopped 检查推导为通过。
- renderer 只有在权威真实集合全部通过时才返回通过；报告可在总体未通过时落盘，但命令必须返回专用非零码。
- 当前算子镜像字节内容不因本计划改变；最终提交会改变仓库 SHA，现场必须按新 SHA 重建/重标平台和算子镜像并重新取证，旧 SHA 证据不能继承为新 SHA 通过。

- [ ] **Step 4: 实现共享合同的最小类型和校验函数**

实现以下公开接口；`CASE_FIELDS` 必须严格拒绝未知/缺失字段，所有 case 均保留 source/run provenance：

```python
import json
from pathlib import Path
from typing import Any, TypedDict


SCHEMA_VERSION = 1
STATUSES = ("通过", "失败", "未执行及原因")
COVERAGE_KEYS = {
    "registration_full",
    "registration_profiles",
    "registration_recovery",
    "registration_facerec",
    "gpu_running",
    "gpu_stopped",
    "smoke_full",
    "smoke_gpu_trigger",
    "smoke_cpu_instance",
    "negative_declarations",
    "load_declarations",
}
CASE_FIELDS = {
    "case_id",
    "source_case_id",
    "case_kind",
    "run_id",
    "status",
    "started_at",
    "finished_at",
    "target",
    "command",
    "evidence",
    "reason",
    "mock",
    "release_tag",
    "git_sha",
}


class Coverage(TypedDict):
    expected: int
    observed: int
    passed: int


class CaseRecord(TypedDict):
    case_id: str
    source_case_id: str
    case_kind: str
    run_id: str
    status: str
    started_at: str
    finished_at: str
    target: str
    command: str
    evidence: list[str]
    reason: str
    mock: bool
    release_tag: str
    git_sha: str


def load_report_plan(path: Path) -> dict[str, Any]:
    document = json.loads(path.read_text(encoding="utf-8"))
    if not isinstance(document, dict) or document.get("schema_version") != SCHEMA_VERSION:
        raise ValueError("report plan schema_version 不受支持")
    if set(document) != {"schema_version", "registration", "smoke", "declarations"}:
        raise ValueError("report plan 包含未知或缺失字段")
    return document


def expand_declaration_cases(plan: dict[str, Any]) -> list[dict[str, str]]:
    result: list[dict[str, str]] = []
    reason = plan["declarations"]["reason"]
    for category in ("negative", "load"):
        for item in plan["declarations"][category]:
            for index in range(item["first"], item["last"] + 1):
                result.append(
                    {
                        "case_id": f"{item['prefix']}-{index:03d}",
                        "category": category,
                        "status": "未执行及原因",
                        "reason": reason,
                    }
                )
    return result


def validate_cases_envelope(document: Any) -> dict[str, Any]:
    if not isinstance(document, dict):
        raise ValueError("cases 输入必须是版本化对象")
    required = {"schema_version", "release_tag", "git_sha", "plan_sha256", "coverage", "cases"}
    if set(document) != required or document["schema_version"] != SCHEMA_VERSION:
        raise ValueError("cases envelope 包含未知、缺失或不支持的字段")
    if set(document["coverage"]) != COVERAGE_KEYS:
        raise ValueError("coverage 集合与权威合同不一致")
    return document
```

同时对 prefix、范围、固定 reason、profile 集合、FaceRec 三实例、40 位小写 SHA、64 位摘要、case ID、字符串类型和控制字符做显式校验，不允许 Python `bool` 冒充整数。

- [ ] **Step 3: 实现 Compose inventory 和规范 registration 路径**

实现 `load_operator_inventory()`，使用 `yaml.safe_load`，要求精确 24 个 services；GPU 实例必须同时拥有单一 `gpu0/gpu1/gpu2` profile、`PLATFORM_GPU_ID`、`GPU_PROCESS_NAME` 和 `PLATFORM_INSTANCE_ID`。CPU 实例必须属于 `cpu` 且没有 GPU process 字段。类型定义和返回顺序固定如下：

```python
@dataclass(frozen=True)
class OperatorInstance:
    service_name: str
    instance_id: str
    operator_code: str
    profile: str
    physical_gpu: int | None
    process_name: str | None


@dataclass(frozen=True)
class OperatorInventory:
    instances: tuple[OperatorInstance, ...]

    @property
    def gpu_instances(self) -> tuple[OperatorInstance, ...]:
        return tuple(item for item in self.instances if item.physical_gpu is not None)

    @property
    def cpu_instances(self) -> tuple[OperatorInstance, ...]:
        return tuple(item for item in self.instances if item.physical_gpu is None)
```

public loader 的精确签名是 `load_operator_inventory(path: Path) -> OperatorInventory`。实现时补齐 `from dataclasses import dataclass`，按 `instance_id` 排序 `instances`，并显式断言 `len(instances) == 24`、`len(gpu_instances) == 18`、`len(cpu_instances) == 6`。拒绝非对象 `services/environment`、重复 instance、service/instance ID 不同、非单 profile、GPU profile 与 `PLATFORM_GPU_ID` 不同，以及 CPU 出现任一 GPU 字段。`operator_code` 使用 Smoke manifest 的下划线编码；GPU 从 `GPU_PROCESS_NAME` 取得，CPU 只允许 `ppt-slice-* -> ppt_slice` 和 `text-analysis-* -> text_analysis`，其 `process_name` 与 `physical_gpu` 都是 `None`。

registration 路径固定为：

```python
def registration_paths(inventory: OperatorInventory) -> dict[str, Path]:
    selected_faces = ["facerec-gpu0", "facerec-gpu1", "facerec-gpu2"]
    face_hash = hashlib.sha256("\n".join(selected_faces).encode()).hexdigest()[:12]
    paths = {
        "full": Path("registration/operator-registration.json"),
        "profile:gpu0": Path("registration/operator-registration-profile-gpu0.json"),
        "profile:gpu1": Path("registration/operator-registration-profile-gpu1.json"),
        "profile:gpu2": Path("registration/operator-registration-profile-gpu2.json"),
        "profile:cpu": Path("registration/operator-registration-profile-cpu.json"),
        "facerec": Path(f"registration/operator-registration-instances-{face_hash}.json"),
    }
    paths.update(
        {
            f"recovery:{instance.instance_id}": Path(
                f"registration/operator-registration-instance-{instance.instance_id}.json"
            )
            for instance in inventory.gpu_instances
        }
    )
    return paths
```

- [ ] **Step 4: 实现 GPU running/stopped 交叉校验和 case 生成**

对每个 Compose GPU 实例要求两个固定文件，并验证：

```python
def validate_gpu_pair(
    instance: OperatorInstance,
    running: dict[str, Any],
    stopped: dict[str, Any],
    git_sha: str,
) -> None:
    if running.get("mode") != "running-inference":
        raise ValueError(f"{instance.instance_id} running mode 不匹配")
    if stopped.get("mode") != "assert-stopped":
        raise ValueError(f"{instance.instance_id} stopped mode 不匹配")
    target = running.get("target")
    if not isinstance(target, dict) or target.get("instance_id") != instance.instance_id:
        raise ValueError(f"{instance.instance_id} target.instance_id 不匹配")
    if target.get("physical_gpu") != instance.physical_gpu:
        raise ValueError(f"{instance.instance_id} physical_gpu 不匹配")
    if target.get("process_name") != instance.process_name:
        raise ValueError(f"{instance.instance_id} process_name 不匹配")
    for label, payload in (("running", running), ("stopped", stopped)):
        status = payload.get("status")
        if status not in {"PASS", "FAIL"}:
            raise ValueError(f"{instance.instance_id} {label} status 不受支持")
        release_sha = payload.get("release_sha")
        if release_sha is not None and release_sha != git_sha:
            raise ValueError(f"{instance.instance_id} {label} release_sha 不匹配")
        if status == "FAIL" and not str(payload.get("reason", "")).strip():
            raise ValueError(f"{instance.instance_id} {label} FAIL 缺少 reason")
    if running["status"] == "PASS":
        if running.get("release_sha") != git_sha:
            raise ValueError(f"{instance.instance_id} running PASS 缺少 release_sha")
        if not isinstance(running.get("container"), dict) or not isinstance(running.get("gpu"), dict):
            raise ValueError(f"{instance.instance_id} running PASS 缺少容器或 GPU 身份")
        if not isinstance(running.get("activity"), dict) or not running.get("synchronous_samples"):
            raise ValueError(f"{instance.instance_id} running PASS 缺少 activity 或同步采样")
    if stopped["status"] == "PASS":
        if running["status"] != "PASS" or stopped.get("release_sha") != git_sha:
            raise ValueError(f"{instance.instance_id} stopped PASS 没有对应 running PASS")
        if stopped.get("container") != running.get("container") or stopped.get("gpu") != running.get("gpu"):
            raise ValueError(f"{instance.instance_id} stopped 与 running 身份不一致")
        if stopped.get("remaining_cuda_pids") != []:
            raise ValueError(f"{instance.instance_id} stopped PASS 仍有 CUDA PID")
```

running/stopped 的 `schema_version=1`、`timestamp`、`mode`、结构化 `target`、非空 `commands` 必须对 PASS/FAIL 都验证；stopped 的 target 也必须逐字段匹配 inventory。FAIL 允许缺少 verifier 尚未来得及取得的 `release_sha/container/gpu/activity/synchronous_samples`，但已出现的字段不得与当前 release、Compose inventory 或配对 running 文件冲突。这样真实失败会成为 `失败` case，而不是让聚合器因套用 PASS schema 丢失失败事实。

case ID 固定为 `GPU-RUN-{instance_id}`、`GPU-STOP-{instance_id}`、`REG-FULL`、`REG-PROFILE-{profile}`、`REG-FACEREC-THREE` 和 `REG-RECOVERY-{instance_id}`。GPU v1 只有一个 `timestamp`，生成 case 时 `started_at` 与 `finished_at` 都使用该值，不读取文件 mtime。coverage 的 `observed` 统计结构合法的文件，`passed` 只统计 PASS；合法 FAIL 不降低 observed。

```python
def classify_evidence(relative_path: PurePosixPath, payload: dict[str, Any]) -> str:
    explicit = payload.get("evidence_type")
    if explicit in {"operator_smoke", "operator_registration", "execution_declaration"}:
        return str(explicit)
    if explicit is None and relative_path.parts[0] == "gpu-instances" and payload.get("mode") == "running-inference":
        return "gpu_runtime"
    if explicit is None and relative_path.parts[0] == "recovery" and payload.get("mode") == "assert-stopped":

    raise ValueError(f"证据类型未知或目录/mode 不匹配: {relative_path}")
```
