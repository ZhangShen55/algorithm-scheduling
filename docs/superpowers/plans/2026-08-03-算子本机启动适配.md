# 算子本机启动适配 Implementation Plan

> 历史说明：本计划记录结构整改前的项目路径；当前路径为 `facerec`、`asr_offline` 和 `asr_online`。

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让 ASR 与人脸算子在当前 Apple Silicon Mac 上使用项目内模型和 CPU 启动，并用现有音频、图片和远程 PPT 视频完成业务冒烟。

**Architecture:** ASR 只调整运行配置与缺失依赖，不改变推理流程。人脸算子将旧的整数 `gpu_id` 配置替换为字符串 `device`，由一个纯函数解析 `cpu` 或 `cuda:N` 并配置 FastDeploy RuntimeOption。PPT 使用现有回调程序接收切片结果。

**Tech Stack:** Python 3.10/3.11、FastAPI、FunASR、FastDeploy、Dlib、pytest、Uvicorn
