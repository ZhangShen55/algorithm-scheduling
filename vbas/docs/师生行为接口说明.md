#  图像检测接口说明

本文档说明  6.0 默认保留的两个图像检测接口：

- `POST /ImageDetect/student/v1.0.0`
- `POST /ImageDetect/teacher/v1.0.0`

接口由  服务提供，默认端口以实例配置为准，例如 `http://10.80.5.128:8981`。

## 通用约定

### 请求头

| 名称 | 必填 | 示例 | 说明 |
| --- | --- | --- | --- |
| `Content-Type` | 是 | `application/json` | 请求体为 JSON |

### 图片输入

`ImageList[].StoragePath` 支持三种形式：

| 类型 | 示例 | 说明 |
| --- | --- | --- |
| HTTP/HTTPS URL | `http://127.0.0.1:18080/student_001.jpg` |  会下载图片后解码 |
| Base64 | `data:image/jpeg;base64,...` | 支持带 data 前缀或纯 Base64 字符串 |
| 文件路径 | `/mnt/ias-images/a.jpg` 或 `a.jpg` | 绝对路径直接读取；相对路径会拼接 `IMAGE_ROOT` |

### 区域裁剪

`ImageList[].Points` 可选。传入后仅对多边形区域内图像做检测，返回坐标会加回区域偏移，仍按原图坐标系输出。

点位结构：

```json
{
  "X": 0,
  "Y": 0
}
```

### 批次标识

`task_id`、`batch_id`、`stream_type` 是可选字段，主要用于 ai_quality 调用  时记录日志、准入控制和问题排查。

### 通用返回结构

```json
{
  "StatusObject": {
    "StatusString": "success",
    "ImageIdList": ["image-001"],
    "TimeStamp": 1750000000,
    "UseTimeMs": 120,
    "StatusCode": 0
  },
  "DataList": [
    {
      "StatusObject": {
        "StatusString": "success",
        "ImageId": "image-001",
        "TimeStamp": 1750000000,
        "UseTimeMs": 100,
        "StatusCode": 0
      },
      "ResultList": [
        {
          "ObjectType": 100,
          "ObjectCount": 1,
          "ObjectPostList": [
            {
              "LeftTopX": 10,
              "LeftTopY": 20,
              "RightBtmX": 100,
              "RightBtmY": 200
            }
          ]
        }
      ]
    }
  ]
}
```

### 返回字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `StatusObject.StatusString` | string | `success` 或 `failed` |
| `StatusObject.ImageIdList` | array | 本次成功处理的图片 ID 列表 |
| `StatusObject.ImageId` | string | 单张图片 ID，仅单图结果内返回 |
| `StatusObject.TimeStamp` | integer | 服务处理时的秒级时间戳 |
| `StatusObject.UseTimeMs` | integer | 耗时，单位毫秒 |
| `StatusObject.StatusCode` | integer | 当前成功为 `0` |
| `DataList` | array | 每张图片的检测结果 |
| `ResultList` | array | 每类目标的检测结果 |
| `ObjectType` | integer | 目标类型编码 |
| `ObjectCount` | integer | 当前目标类型检测数量 |
| `ObjectPostList` | array/null | 目标框列表；数量为 0 时可能为 `null` |
| `LeftTopX` | integer | 目标框左上角 X |
| `LeftTopY` | integer | 目标框左上角 Y |
| `RightBtmX` | integer | 目标框右下角 X |
| `RightBtmY` | integer | 目标框右下角 Y |
| `Confidence` | number/null | 目标置信度；当前教师接口会返回，学生接口通常不返回 |
| `SuspectedSitting` | boolean/null | 教师站坐冲突时的疑似坐标记，仅教师接口可能返回 |
| `PostureFallback` | boolean/null | 教师姿态缺失时使用默认姿态回退，仅教师接口可能返回 |

### HTTP 错误

| HTTP 状态码 | 场景 |
| --- | --- |
| `422` | JSON 字段类型不符合 Pydantic 校验，例如 `ImageList` 缺失 |
| `429` |  实例满载，且未开启本地队列 |
| `503` |  排空中，或本地队列已满 |
| `500` | 图片读取失败、模型推理异常或其他服务内部异常 |

## 学生图像检测接口

### 接口

```text
POST /ImageDetect/student/v1.0.0
```

### 功能

对学生画面做人数、人脸和学生行为检测。当前实现会并行调用三类模型：

- 人数检测模型：统计可见学生目标。
- 人脸检测模型：统计可见人脸，可作为抬头人数使用。
- 学生行为模型：检测玩手机、举手、睡觉、站立、阅读。

### 请求体

```json
{
  "task_id": "lesson-test-001",
  "batch_id": "student-batch-0001",
  "stream_type": "student",
  "Student_Thresd": {
    "phone": 0.7,
    "hand": 0.99,
    "sleep": 0.5,
    "stand": 0.99,
    "read": 0.5
  },
  "ImageList": [
    {
      "ImageId": "student-frame-0001",
      "StoragePath": "http://127.0.0.1:18080/student_0001.jpg",
      "frame_id": "student-frame-0001",
      "frame_index": 1,
      "timestamp_seconds": 10.0,
      "Points": [
        {"X": 0, "Y": 0},
        {"X": 1920, "Y": 0},
        {"X": 1920, "Y": 1080},
        {"X": 0, "Y": 1080}
      ]
    }
  ]
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `ImageList` | array | 是 | 图片列表，至少 1 张 |
| `ImageList[].ImageId` | string | 是 | 图片唯一标识 |
| `ImageList[].StoragePath` | string | 是 | 图片 URL、Base64 或文件路径 |
| `ImageList[].Points` | array | 否 | 检测区域多边形，不传表示全图检测 |
| `ImageList[].frame_id` | string | 否 | 帧 ID，当前主要用于调用方追踪 |
| `ImageList[].frame_index` | integer | 否 | 帧序号，当前主要用于调用方追踪 |
| `ImageList[].timestamp_seconds` | number | 否 | 帧时间戳，单位秒，当前主要用于调用方追踪 |
| `Student_Thresd.phone` | number | 否 | 玩手机阈值，范围 `0.0-1.0` |
| `Student_Thresd.hand` | number | 否 | 举手阈值，范围 `0.0-1.0` |
| `Student_Thresd.sleep` | number | 否 | 睡觉阈值，范围 `0.0-1.0` |
| `Student_Thresd.stand` | number | 否 | 站立阈值，范围 `0.0-1.0` |
| `Student_Thresd.read` | number | 否 | 阅读阈值，范围 `0.0-1.0` |
| `task_id` | string | 否 | 任务 ID |
| `batch_id` | string | 否 | 批次 ID |
| `stream_type` | string | 否 | 流类型，建议传 `student` |

未传 `Student_Thresd` 时使用 `/config.toml` 中 `[Student_Thresd]` 的配置。

### ObjectType 编码

| ObjectType | 名称 | 说明 |
| --- | --- | --- |
| `100` | `person_count` | 人数检测结果 |
| `101` | `face` | 人脸检测结果，可作为抬头人数 |
| `201` | `Using_phone` | 学生玩手机 |
| `202` | `Sleep` | 学生睡觉 |
| `203` | `Hand_raising` | 学生举手 |
| `204` | `standing` | 学生站立 |
| `205` | `Read_W` | 学生阅读 |

## 教师图像检测接口

### 接口

```text
POST /ImageDetect/teacher/v1.0.0
```

### 功能

对教师画面做教师主体、站立、坐着、板书、讲授检测。可选返回教师头姿结果。

头姿检测需要同时满足：

- 请求中 `ReturnHeadPose=true`。
- `/config.toml` 中 `[Teacher_Head_Pose].Enabled=true`。
- 当前图片检测到了教师主体。

### 请求体

```json
{
  "task_id": "lesson-test-001",
  "batch_id": "teacher-batch-0001",
  "stream_type": "teacher",
  "ReturnHeadPose": false,
  "Teacher_Behavior_Thresd": {
    "sit": 0.4,
    "stand": 0.4,
    "bbwriting": 0.25,
    "teach": 0.25
  },
  "ImageList": [
    {
      "ImageId": "teacher-frame-0001",
      "StoragePath": "http://127.0.0.1:18080/teacher_0001.jpg",
      "frame_id": "teacher-frame-0001",
      "frame_index": 1,
      "timestamp_seconds": 10.0
    }
  ]
}
```

### 请求字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `ImageList` | array | 是 | 图片列表，至少 1 张 |
| `ImageList[].ImageId` | string | 是 | 图片唯一标识 |
| `ImageList[].StoragePath` | string | 是 | 图片 URL、Base64 或文件路径 |
| `ImageList[].Points` | array | 否 | 检测区域多边形，不传表示全图检测 |
| `Teacher_Behavior_Thresd.sit` | number | 否 | 坐着阈值 |
| `Teacher_Behavior_Thresd.stand` | number | 否 | 站立阈值 |
| `Teacher_Behavior_Thresd.bbwriting` | number | 否 | 板书阈值 |
| `Teacher_Behavior_Thresd.teach` | number | 否 | 讲授阈值 |
| `ReturnHeadPose` | boolean | 否 | 是否请求返回头姿，默认 `false` |
| `task_id` | string | 否 | 任务 ID |
| `batch_id` | string | 否 | 批次 ID |
| `stream_type` | string | 否 | 流类型，建议传 `teacher` |

未传 `Teacher_Behavior_Thresd` 时使用 `/config.toml` 中 `[Teacher_Behavior_Thresd]` 的配置。

### ObjectType 编码

| ObjectType | 名称 | 说明 |
| --- | --- | --- |
| `100` | `platform_person` | 讲台教师主体 |
| `201` | `sitting` | 教师坐着 |
| `202` | `standing` | 教师站立 |
| `203` | `writing` | 教师板书 |
| `204` | `teaching` | 教师讲授 |

### 教师行为输出口径

当前教师行为模型会先把同一主体的高 IoU 多类别框合并，再输出主体行为：

- 默认只保留一个主教师主体，配置项为 `KeepOnlyMainSubject=true`。
- 站立和坐着同时出现时，按置信度差异和 `PostureConflictRatio` 判断。
- 如果站立/坐着缺失，并且 `ForcePostureWhenMissing=true`，会按默认姿态回退，返回 `PostureFallback=true`。
- 坐站冲突走默认站立时，可能返回 `SuspectedSitting=true`。

这些策略由 `/config.toml` 的 `[Teacher_Behavior_Thresd]` 控制。

### HeadPoseResult 字段

当返回头姿时，单张图片结果中会包含 `HeadPoseResult`。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `Enabled` | boolean | 头姿检测是否启用 |
| `Status` | string | 头姿检测状态 |
| `FaceDirection` | string | 面向方向，如 `front`、`left`、`right`、`unknown` |
| `Yaw` | number/null | 偏航角 |
| `Pitch` | number/null | 俯仰角 |
| `Roll` | number/null | 翻滚角 |
| `Angle` | number/null | 超出侧向阈值后的角度 |
| `IsLookingDown` | boolean/null | 是否低头 |
| `HeadPoseConfidence` | number/null | 头姿置信度 |
| `TeacherConfidence` | number/null | 教师主体置信度 |
| `TeacherSubjectBox` | object/null | 教师主体框 |
| `HeadBox` | object/null | 头部框 |
| `Message` | string/null | 补充信息或失败原因 |

```bash

  -H "Content-Type: application/json" \
  -d '{
```
