## 已知限制

- 仍使用连续两次在线空输出及保护上限结束字幕；空输出不等于物理静音，不保证真实句法断句。
- 锚点不足、重复短语或模型不同的末尾表达会拒绝该次句中结果；通过功能检查不等于每句均被纠正，也不保证每次改写更准确。
- 句末总等待预算为 100 ms，在线缓存 flush 的必要执行时间可能消耗此预算；不等待迟到纠正，回退保留已采纳前缀和完整尾部。
- 首轮 GPU 汇总脚本未解析日志中嵌套的事件字段，误计采纳为零，已修复并重新验证。早期结果保留用于排查，以 verified 目录为交付依据。
- Mac 进程退出时出现 Python multiprocessing 的 semaphore 清理提示；端口和测试进程已退出。此次未开展长时资源稳定性验证。
- 原有 Docker 与 Cython 构建均递归包含 `app/`，新增模块沿用相同目录，无需新运行入口；本轮未构建 Docker 镜像。
