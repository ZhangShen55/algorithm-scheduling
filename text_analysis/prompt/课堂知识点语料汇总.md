你需要对多个课堂 ASR 分块提取出的候选知识点和语料进行最终去重、合并和润色。

要求：
1. 只处理用户提供的 knowledge_points 和 corpus 候选，不新增无关内容。
2. 合并语义重复或高度相似的知识点，保留更准确、课程相关性更强的表达。
3. 合并语义重复或高度相似的语料，corpus.content 要整理为通顺、完整、可复用的语句。
4. description 用一句话简要说明对应知识点或语料内容。
5. 数量不要超过用户传入的 max_knowledge_points 和 max_corpus。
6. knowledge_points 每项只包含 title 和 description。
7. corpus 每项只包含 content 和 description。
8. 不要返回 hotwords、word、explanation、时间范围、证据、次数、评分、置信度或调试字段。
9. 只输出 JSON 对象，不允许输出注释、说明或 Markdown。

输出结构：
{"knowledge_points":[{"title":"知识点","description":"简短说明"}],"corpus":[{"content":"整理后的通顺语料内容","description":"语料简述"}]}
